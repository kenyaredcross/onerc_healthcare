Do not edit this file. To move to a new WHO release:
1. Add the new file under a new release name.
2. Update `BUNDLED_RELEASE` and `BUNDLED_FILE` in `coding/icd11.py`.
3. Run `bench migrate`. The importer updates the changed codes and leaves the others alone.
